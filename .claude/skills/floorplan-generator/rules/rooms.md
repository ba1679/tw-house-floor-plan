# 房間與尺寸

## 坪數：預設當作權狀坪數

台灣人說「25 坪」幾乎都是指**權狀坪數（含公設）**。直接拿它換算成室內面積會畫出
大得不像話的房子。

```
權狀坪數 × (1 − 公設比) = 室內坪數
室內坪數 × 3.305785 = m²
```

`public_ratio` 預設 **0.32**。使用者沒講就用預設，並在回覆裡**明講這個假設**。
換算結果會寫進 `area_meta` 並印在圖上，不要藏起來。

| 產品型態 | 公設比 |
|---|---|
| 電梯大樓（新成屋） | 30–35% |
| 華廈 | 25–30% |
| 無電梯公寓 | 0–10% |

若使用者明確說「室內 25 坪」「實際使用 25 坪」，改用 `area.bounds` 直接給尺寸，
或把 `public_ratio` 設 0。

## 長寬比

`aspect` = width / height，預設 1.25。

- 電梯大樓單層戶：1.1 – 1.4
- 長型街屋 / 老公寓：2.5 – 3.5（此時建議直接給 `bounds`，並設 `party_walls: ["w","e"]`）

## 房數對照

| 權狀坪數 | 常見配置 |
|---|---|
| 10–15 | 套房（開放式 1 房 1 衛） |
| 16–22 | 2 房 1 衛 |
| 23–30 | 2 房 2 衛，或 3 房 1 衛 |
| 31–40 | 3 房 2 衛 |
| 41+ | 4 房 2 衛 |

## 各空間的下限（室內淨尺寸）

低於這些數字就會被 validator 抓到「放不下傢俱」或「淨寬不足」。

| 空間 | 最小面積 | 最小短邊 | 備註 |
|---|---|---|---|
| 主臥 | 3.0 坪 | 260 cm | 床 + 衣櫃需淨深 ≥ 250、淨寬 ≥ 240 |
| 次臥 | 2.0 坪 | 220 cm | |
| 小孩房 | 1.5 坪 | 180 cm | 單人床 91×188 直擺 |
| 客廳 | 4.0 坪 | 300 cm | 沙發 + 電視距離 |
| 餐廳 | 2.0 坪 | 220 cm | 四人餐桌 140×80 |
| 廚房 | 1.5 坪 | 180 cm | 一字型檯面 240cm；**淨深須 ≥ 120cm**（檯面 60 + 通行 60） |
| 衛浴 | 1.0 坪 | 140 cm | **淨深 < 150cm 就放不下獨立淋浴間**，此時不要放 `shower` |
| 走道 | — | 90 cm | 最低 80 cm |
| 陽台 | 1.0 坪 | 90 cm | |

這些數字是**扣掉門的開啟弧線與 60cm 通行空間之後真的放得下**的下限，不是舒適值。
低於它，展開器會直接報「放不進」並列出每面牆還剩多少。

坪數越小越要克制：20 坪以下不要同時要求「床 + 衣櫃 + 書桌」，也不要在 1 坪衛浴裡放淋浴間。

## 動線：先想清楚誰通到誰

validator 會從 `role: "entrance"` 的大門做 BFS，**任何走不到的房間都是硬錯誤**。

台灣格局的兩種主流解法：

**A. 中央走道（>= 20 坪建議用這個）**

```
        ┌──────────┬────┬──────────┐
        │ 客廳     │    │ 主臥     │
        │ 廚房     │走道│ 衛浴     │
        │ 陽台     │    │ 次臥     │
        └──────────┴────┴──────────┘
```

走道當成一個 `hallway` 葉子，所有房間都與它相鄰，每間開一道門。
這是最不容易出錯的結構——照抄 `examples/02` 和 `examples/03`。

**B. 客廳即動線核心（小坪數）**

房間直接開門到客廳。這時要特別檢查**共用邊夠不夠寬**（至少要比門寬多 20cm），
否則展開器會報「共用段只有 N cm」。

**不要讓臥室當通道。** 若某間臥室有兩道以上通往非衛浴空間的門，validator 會警告——
除非那正是你要示範的問題（見 `examples/05` 長型街屋）。

## 採光

`living_room / dining_room / bedroom / master_bedroom / study` 沒開窗會被警告為暗房。
窗戶只能開在 `exterior` 牆（`party` 牆不行）。

若格局本身就會產生暗房（長型街屋、中間房），**不要為了消警告硬塞窗戶**——
保留警告，並在回覆裡說明這是該格局的真實限制。
