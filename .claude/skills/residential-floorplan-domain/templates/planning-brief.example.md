# 住宅平面配置 Planning Brief

## 基本假設

- 地區：TW
- 建築類型：集合住宅
- 坪數口徑：25 坪視為權狀坪數，公設比暫以 0.32 計算
- 未知但會影響判斷的資料：立管位置、樓板降板、排水坡度、結構柱與實際窗向尚未提供

## 空間分類

| 空間 | 類別 | 主要需求 |
|---|---|---|
| 客廳 | DRY_AREA | 採光、公共動線 |
| 主臥 | DRY_AREA | 私密、床與衣櫃使用空間 |
| 衛浴 | WET_AREA | 馬桶、面盆、淋浴、通風、維修 |
| 廚房 | WET_AREA | 檯面、冰箱、餐區動線 |
| 管道間 | SERVICE_AREA | 立管、檢修可達 |

## 鄰接與服務核心

```text
管道間 -> 衛浴（prefer_near，降低管路複雜度）
管道間 -> 廚房（prefer_near，避免跨越大量乾區）
廚房 -> 餐區（prefer_near，縮短備餐動線）
```

## 規則決策

- 衛浴距管道間：SOFT_CONSTRAINT；先檢查距離與可能排水路徑
- 衛浴通風：UNKNOWN；需確認外窗或機械排氣
- 主臥家具：HARD 使用條件；必須驗證床、衣櫃與開門活動空間

## 給 geometry generator 的輸入

先配置管道間與濕區，再選中央走道骨架；以 `layout.schema.json` 描述拓樸，不直接寫座標。

## 不應宣稱

這是概念配置 brief，不是建照、施工圖、結構圖、消防圖、給排水施工圖或電氣圖。
