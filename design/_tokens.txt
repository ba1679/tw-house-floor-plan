/* ================================================================ 熱區狀態（--state-*）與圖上記號（--mark-*） */

所有線寬都是螢幕 px（non-scaling），線畫在熱區**外側**：線的內緣貼著熱區邊緣，不壓住熱區裡的符號線條。
填色是不透明色，以 mix-blend-mode: multiply 疊上去：紙變色，熱區裡的墨線不變淡。

:root {
  --state-blue: oklch(0.44 0.15 256);         /* 你的操作。對 --fp-paper 7.90:1，對 --fp-wall 3.32:1 */
  --state-warm: oklch(0.45 0.1 65);           /* 別人替你標的。對 --fp-paper 7.64:1，對 --fp-wall 3.21:1 */
  --state-casing: #ffffff;                    /* 白襯邊 */

  --state-normal-fill:   oklch(0.965 0.018 250);
  --state-normal-stroke: var(--state-blue);
  --state-normal-width:  1px;

  --state-candidate-fill:   oklch(0.905 0.045 250);
  --state-candidate-stroke: var(--state-blue);
  --state-candidate-width:  2px;

  --state-selected-stroke: var(--state-blue);
  --state-selected-width:  3px;

  --state-highlighted-fill:   oklch(0.85 0.17 90);   /* 螢光筆滿底，灰階 L 0.85（normal 是 0.97） */

  --mark-circle-stroke: var(--state-blue);    /* 候選圈：實線、不填 */
  --mark-circle-width:  1.5px;

  --mark-check-width:  4px;
  --mark-check-casing: 2.5px;                 /* 兩側白襯邊，圓頭圓角 */
  --mark-check-size:   20px;                  /* 勾的轉折點在 selected 右上角正上方；勾連白襯邊的下緣貼著鍵盤焦點環的外緣（離熱區 9px）。2026-09-19 改，理由見 DESIGN.md */
}

各層的疊放順序（下到上）：圖面 → 填色（multiply）→ 候選圈 → normal、highlighted、candidate、revealed、selected 的線 → 答對的勾 → 鍵盤焦點。
