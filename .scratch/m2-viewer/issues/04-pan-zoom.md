# 04: pan/zoom 手勢

**What to build:** 使用者可以自己決定要細看圖的哪一區：雙指縮放、拖曳平移、雙擊快速放大、一鍵回到全圖。兩段式點擊解決的是「點得到」，pan/zoom 解決的是「看得清楚」，兩者都要有（PRD §6.1.1）。

**Blocked by:** 02（兩段式點擊選到符號）

02 已經把換算層建在 CSS transform 上，這張票加的是使用者發起的手勢，不重寫換算。

**Status:** ready-for-agent

- [ ] pinch zoom（雙指縮放）
- [ ] drag pan（拖曳平移）
- [ ] double tap zoom（快速放大到該區域）
- [ ] reset view（一鍵回到全圖）
- [ ] 縮放有上下限，使用者不會把圖縮成一點或放大到只剩一條線
- [ ] 手勢與兩段式點擊不互相誤觸：拖曳不應被判定成一次 tap
- [ ] 縮放後兩段式的容錯半徑跟著換算——46 CSS px 在任何倍率下都是 46 CSS px，換算出的圖面公分數隨倍率改變
- [ ] 平移與縮放在手機上維持順暢（優先 CSS transform，避免每幀重繪 SVG）
- [ ] `fitLocked` 為真時，使用者發起的縮放全部被擋，但兩段式的自動 3× 照常發生
- [ ] 測試涵蓋：放大後點擊仍選得到正確的熱區；`fitLocked` 擋得住使用者縮放卻擋不住自動放大
