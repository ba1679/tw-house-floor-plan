# 06: 鍵盤與無障礙

**What to build:** 鍵盤使用者能看完整張圖。兩段式點擊升為全站基礎操作之後，它是**所有人看圖的唯一方式**——所以鍵盤必須有一條完整的平行路徑，否則這個網站對鍵盤使用者等於不存在。

鍵盤路徑**不走兩段式**：兩段式解的是手指精度問題，鍵盤沒有這個問題。

**Blocked by:** 03（說明卡 bottom sheet）— Enter 要開得出說明卡

**Status:** ready-for-agent

- [ ] **Tab 的閱讀順序：依房間，房間內依符號類別**（結構 → 門窗 → 家具家配）。這解掉了 PRD §9 標為「v0.5 未決、實作前必須先定」的問題
- [ ] 房間順序對上「看屋時一間一間看」的心智模型（玄關 → 客廳 → 餐廳 → 廚房 → …）
- [ ] hotspot 的房間歸屬**在 build 時由 `floorplan.rooms` 的幾何算出，不改 floorplan schema**——floorplan 由程式產生、不得手改，加欄位就要動 `expand_layout.py` 與所有既有產物
- [ ] 落在所有 room 之外的 hotspot（雨遮、外牆、外側的窗）歸到幾何上最近的 room，排在該房間的最後
- [ ] Enter 開啟說明卡，Esc 關閉
- [ ] 每個熱區有替代文字，內容為該 symbol 的 `name`
- [ ] 焦點在熱區間移動時，該熱區在畫面上有明確的視覺焦點狀態
- [ ] 焦點移到畫面外的熱區時，圖自動捲動或平移使其可見
- [ ] 說明卡開啟時焦點移入卡片；關閉後焦點回到原本的熱區
- [ ] 測試涵蓋：Tab 序列符合「依房間、房間內依類別」；Enter 開卡、Esc 關卡且焦點回到原熱區
