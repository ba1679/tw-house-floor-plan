# 07: 拆掉 `?fitLocked=1`

**What to build:** 平面圖頁不再有「網址加一個參數就能把圖鎖死、畫面上又沒有任何東西能解開」的後門。視野鎖定只在找找看出題時打開——那正是 M2 留下這個參數時在等的正式入口。

**Blocked by:** 02（刪掉「鎖定視野」那個測試變體的前提是「下一題」會收起說明卡）

**Status:** ready-for-agent

規格：`.scratch/m4-quiz/spec.md` 的「移除 `?fitLocked=1`」與「既有測試要跟著動的」。

## 注意

- **狀態機的視野鎖定開關不動**，只拆「從網址讀」這個入口
- **「擋得住使用者發起的縮放，擋不住第一段的自動放大」那條測試搬到找找看頁**：按「開始」之後照原本的步驟驗
- **「展開說明卡後直接點圖上另一個符號」的「鎖定視野」變體刪除。** 找找看裡：說明卡只在作答後打開（作答前唯一會開卡的路就是選定熱區，那一下就是作答）、作答後圖暫停、「下一題」收起說明卡——三件合起來，那個情境不會發生。「一般模式」變體保留
- 若 02 沒有驗到「展開狀態下按『下一題』也會收起說明卡」，**先不要刪**，回頭補 02

- [ ] 「鎖定視野」變體已刪除；「一般模式」變體仍在且綠
- [ ] 程式裡不再有從網址讀視野鎖定的地方
