# 02: 作答之後——答案標出來、答錯當場學

**What to build:** 題目是窗，他點到了柱。圖上 9 扇窗全部標出來，他點到的那根柱也留著標記——他分得出自己是點歪還是認錯。說明卡直接打開**窗**的說明，第一句是「你點的是柱」。他關掉卡片再看一眼圖，標記還在；按「下一題」才清掉。

答對的話，他點的那扇窗打勾，**另外 8 扇也標出來**——主圖的窗畫了三種，他剛剛認得的只是其中一種。說明卡不自動彈出，想看再按「看說明」。

**Blocked by:** 01（一局要先玩得動，才有「作答之後」）

**Status:** ready-for-agent

規格：`.scratch/m4-quiz/spec.md` 的「作答之後、按『下一題』之前」。

## 注意

- **暫停的形狀、說明卡由外部指定符號，照 01 動手前那次 `/codebase-design` 的結論做。** 若那次決定新增 stage 或外包一層而還沒寫 ADR，這張補上（難逆、會被問、有具體被拒絕的替代方案）
- **`revealed` 不是 `highlighted`**：形狀相同（一個符號的每一處），壽命不同——`highlighted` 在使用者開始選東西時就清掉（ADR-0006），`revealed` 留到按「下一題」。不得共用同一個欄位或同一個畫面狀態值，畫面上也要分得出來：從符號頁帶著高亮進平面圖的人，不該以為自己在答題
- **關閉說明卡在自由看圖 = 回到 browsing；在找找看不是。** 關掉卡片不清標記、不解除暫停
- **「下一題」一定收起說明卡，展開著也收。** 帶著展開的卡進下一題，就是 M2 票 08 修過的那個情境（卡片展開時 fit 很小，第一段的定位會被夾回圖中央），而鎖定視野時連補救的平移都沒有。07 刪測試靠的就是這一條
- **差異句**取**題目那一側** `confused_with` 那一筆的 `difference`；題目的 `confused_with` 裡沒有被點中的符號，就只有「你點的是 X」。**不為此補登資料**：圖上最常點錯的柱與相鄰的窗是位置相鄰、不是畫法相似
- **說明卡的出現次數只留「共 N 處」**：每一處已經都標在圖上，而答錯時 `selected` 不是那個符號，「第 M 處」數不出來
- **房間變暗**（說明卡開著時，M2 票 07）：有 `selected` 或 `revealed` 熱區的房間亮，其餘暗。照自由看圖只亮被點中那一間的規則，答錯時題目符號所在的房間反而會被壓暗

## Acceptance criteria

- [ ] 答對：被點中的是 `selected`，題目符號的其餘各處是 `revealed`；說明卡沒有自動打開
- [ ] 答對後按「看說明」：打開題目符號的說明卡，**沒有**「你點的是」那一句
- [ ] 答錯：題目符號的每一處是 `revealed`，被點中的是 `selected`；說明卡自動打開且顯示題目符號；卡上有「你點的是 X」
- [ ] 答錯且 X 在題目的 `confused_with` 裡（例：題目柱、點牆）→ 卡上有那一筆 `difference` 原文；不在裡面（例：題目窗、點柱）→ 沒有差異句
- [ ] 找找看的說明卡有「這張圖上共 N 處」，沒有「目前第 M 處」，也沒有「看它在圖上的其他位置」
- [ ] 作答後：點圖、雙擊、雙指、拖曳、鍵盤 Enter／空白鍵都不改變任何熱區的狀態
- [ ] 關閉說明卡後、說明卡升降使框高度改變後：`selected` 與 `revealed` 都還在，仍在暫停
- [ ] 「下一題」：標記清掉、題號前進、視野回到全圖、暫停解除；說明卡在展開狀態下按「下一題」也會收起
- [ ] 答錯時，有 `revealed` 熱區的房間沒有被壓暗
- [ ] `revealed`、`highlighted`、`candidate`、`selected` 四者的 computed style 彼此不同
- [ ] 平面圖頁自由看圖的行為不變：關卡片仍回到 browsing、說明卡仍有「第 M 處」與切換鍵（既有測試維持綠）
