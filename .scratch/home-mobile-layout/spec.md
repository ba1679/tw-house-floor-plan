# 首頁排版與手機品牌開場

## User request

首頁缺少排版設計感，希望第一眼能吸引使用者繼續探索；手機的完整台灣 logo 沉到最下面尤其可惜。

## Direction

保留拼厝既有視覺語言，用標題層級、留白與不對稱分欄加強編輯感。完整台灣拼圖與引言相鄰，在手機第一屏出現；真實圖面與「讀這張圖」仍是主要內容與行動。搜尋、分類、練習與品牌承諾保留既有內容和用途。

## Acceptance

- 完整標記在首頁開場的獨立品牌面，DOM 位置與視覺位置一致，不位於搜尋、練習之後。
- 375 × 812 與 320 × 568 首屏同時可見完整標記、網站用途、真實縮圖和完整讀圖按鈕；圖面面積大於標記。
- 中文標題依句意分組換行，桌機形成引言／品牌、圖面／工具的清楚分欄。
- 保留既有 route、可存取名稱、搜尋、Analytics、metadata、JSON-LD 和資料來源。
- 點擊目標至少 44px，保留黑白焦點雙環；窄螢幕、搜尋結果、長文字與放大後不水平溢出。

## Boundary

只調整首頁結構和 CSS、更新直接相關的既有回歸測試及設計規則。圖面、符號資料、房型色、State 與其他頁面的操作不改變。
