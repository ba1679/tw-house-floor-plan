# 家具與尺寸判讀：拆票提案

Status: ticketed

本提案依已確認 spec、C 設計 brief 及架構草案整理。2026-10-04 使用者要求依本提案 breakdown tasks；八張獨立實作／驗收票已發布到本 feature 的 `issues/` 目錄。本檔保留拆票理由與依賴總覽，逐票驗收以 issue 檔案為準。

每張程式交付票都包括該段正式內容查證、必要資料／生成／呈現、建置檢查、真瀏覽器測試及受影響的既有回歸，不另開一串只有 schema、樣式或測試的橫向票。增量版本只導覽到已可用內容，不留死連結或宣稱未交付功能已完成。

## 01：讀懂家具示意的第一個完整步驟

**Blocked by:** None（可立即開始）。

**交付：** 可直接開啟的一步導讀，呈現現有主臥局部圖、白話觀察與可核對依據，並回到完整格局；以 C 的圖文比例驗證第一條完整閱讀路徑。

- 第一批正式家具示意內容與資訊限制完成查證；不直接發布概念稿文字。
- 初步單一內容來源、消費者投影及建置驗證，隨這一個真實步驟落地，不做通用課程引擎。
- 教學圖沿用生成的 FloorPlan 與 Renderer，具備最小局部呈現、合理留白及等價文字；不手改資料或另畫床。
- 手機與桌面可讀，核心理由可見；鍵盤及返回全圖可用，不增加保存狀態。
- 共用圖面預設行為不變；新步驟與受影響的既有流程有測試。

## 02：找出尺寸依據，分清外框與房間可用資訊

**Blocked by:** 01。

**交付：** 第二步能指出尺寸量的是哪一段、哪個單位，以及圖中仍缺少的房間／家具資訊；可與第一步前後切換。

- 圖面端點、單位、文字與說明一致，讀者不用目測或讀取隱藏幾何。
- 明確區分外框尺寸、房間淨尺寸及家具示意；不把既有面積當成床一定放得下的證據。
- 若本批幾何示例增加尺寸，明列假設、可重算條件及可見標註；只增補必要定位，不做通用內尺寸引擎。
- 建置能攔下無效圖面參照及不一致尺寸依據；未知不當成零。
- 步驟切換、焦點、窄螢幕及必要的尺寸回歸都有可觀察測試。

## 03：家具放入後，還要確認哪些使用空間

**Blocked by:** 02。

**交付：** 第三步把尺寸判讀連到走動、開門與使用櫃子所需的資訊，讓讀者知道「放得下」尚未回答哪些問題。

- 延用前兩步的圖面與明列條件，將門扇或櫃子等觀察位置與解釋連起來。
- 不將生成器的預設留空數字當成法規或通用舒適門檻；無依據的數字不發佈。
- 幾何示範只說明明列條件內的關係，未知部分轉成具體追問，不做個人適用判定。
- 前後閱讀、可核對依據、等價文字及手機可操作；本步內容、資料與頁面驗證隨票完成。

## 04：把資訊缺口變成追問，取得可列印清單

**Blocked by:** 03。

**交付：** 第四步完成導讀，並提供可直接開啟、含三至五個問題及詢問理由的固定清單；可以列印帶去詢問建商。

- 問題對應前三步已查證的缺口；不只是通用提醒或未確認的法律承諾。
- 導讀與清單共用內容，不用兩份互相矛盾的問題文字。
- 清單不受導讀、練習結果或儲存狀態限制；螢幕版和列印版都有完整問題與理由。
- 列印不含導覽／操作，不裁切必要內容；用列印 media 測試並檢視實際預覽。
- 四步切換與返回格局可完整示範；不連到尚未完成的練習。

## 05：用陌生局部圖完成第一道判讀作答

**Blocked by:** 02。

**交付：** 用一張未在導讀解過的新局部圖，完成「有依據的結論」一題：選項 → 確認 → 正誤與理由 → 重試。

- 新範例由生成流程產生，明列可見條件；不出現在公開完整 Layout 清單，不新增一戶完整格局。
- 正解唯一，所有選項與理由對應可見資料；內部尺寸不成為已知，也不在題前洩漏答案。
- 判讀練習持有自己的作答，不偽造 Symbol／Hotspot id、不讀寫 Familiarity。
- 選了選項仍可更改，確認後才出回饋；文字與形狀表意，鍵盤及輔助技術可完成。
- 新題資料的建置驗證、正誤／重試及儲存不可用測試隨票完成。

## 06：三題練習與全站入口串成完整使用流程

**Blocked by:** 04、05。

**交付：** 補齊「尚缺資訊」與「有效追問」兩題，完成導讀 → 三題回饋 → 清單／回看／重試，並加入首頁與格局頁的必要入口。

- 同一陌生圖的三題順序、條件與回饋一致；第三題的追問與已完成的第四步／清單語意一致。
- 每題需確認，回饋不自動跳走；三題結束不設總分、通過標章或房屋評分。
- 清單與練習均無前置學習資格；入口可辨識，不把判讀練習命名為找找看。
- 首頁保留主 CTA；格局頁不因入口而增加常駐列、覆蓋圖面或壓縮必要可視帶。
- 完整旅程、直接開清單、回看／重試、既有熟悉度不變、鍵盤及目標螢幕尺寸都有測試；既有 Analytics 語意不被冒用為新作答事件。

## 07：備妥可執行的陌生範例試用與驗收材料

**Blocked by:** 06。

**歷史交付：** 本票已依原受主持流程完成；2026-10-05 後的公開自填流程由 08、09 票接續。

**交付：** 維護者可使用最終可試用版本，配合另一張未在導讀或練習解過的局部圖、一致的訪談說明與記錄表，執行五人獨立判讀試用。

- 試用圖與條件同樣可核對，不用原練習換選項冒充陌生範例。
- 讀者材料不含答案提示；主持者另有核對依據與「三項皆獨立完成才達標」的判定說明。
- 記錄理解結果、所需提示與重複誤解；不捏造五人結果、招募日期或市場證據。
- 整合確認正式來源、答案唯一性、列印預覽、完整頁面旅程、靜態建置及共享圖面的回歸紀錄。
- 到此只能宣告可試用，不能宣告人工教學驗收通過。

## 08：備妥公開自填試用入口與回收表單（2026-10-05 新方向）

**Blocked by:** 07。

**預計 Status:** ready-for-agent。

**交付：** Threads 招募連結可引導讀者自行走完導讀、練習、另一張局部圖及匿名表單；維護者可取得三段原始文字回答。

- 提交前不顯示答案／他人回覆；收最少的背景與流程自述，不要求個資或登入。
- 驗證公開頁面的順序、表單提交與匯出，以及手機、鍵盤、靜態建置及受影響的回歸。
- GA 只作聚合流量輔助，不替代逐份文字判讀。

## 09：招募公開試用，分析回答並修正反覆誤解

**Blocked by:** 08。

**預計 Status:** ready-for-human（需要實際發布招募連結及真實讀者回覆）。

**交付：** 依預先記錄的條件整理真實回覆，逐份判讀三項任務、修正反覆誤解並交付有限制說明的報告。

- 分開報告自述符合目標買房情境者與其他回覆，記有效／排除數量及理由。
- 修正後以新版本的後續回覆再觀察，不把兩版混成同一批。
- 不使用原 `4/5` 門檻，不宣稱公開便利樣本能證明一般買房者的學習成效。
