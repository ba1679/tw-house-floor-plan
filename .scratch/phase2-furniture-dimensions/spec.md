# Phase 2 第一個里程碑：家具示意與尺寸判讀

Status: ready-for-agent

需求確認：2026-10-03～2026-10-04 的 grill-me → grilling 訪談；使用者逐輪採納 Q1–Q13 建議，並確認完整需求摘要。
產品：拼厝（Phin-Chhù）。本 spec 只詳細規範 Phase 2 的第一個可試用里程碑；後續主題不構成本次交付。
依循：根目錄的 CONTEXT.md、DESIGN.md，以及 ADR-0001、0003、0004、0005、0007、0009。

## Problem Statement

優先服務正在看預售屋／新成屋的一般買房者。他們可能已能認出床、門、窗與房間，卻仍把建案平面圖中的家具示意當成實際可用空間的證明。例如，看到房間畫有雙人床，就以為自己的床一定放得下，而且擺放後仍能走動、開門或使用櫃子。

Phase 1 已有互動式平面圖、符號解釋與找找看。這些能力主要回答「圖上的東西是什麼」，尚未形成「哪些結論有圖面依據、哪些資訊還缺少、應向建商追問什麼」的學習流程。

Phase 2 的問題優先序為：把示意當成事實、住起來不合需求、誤以為買後能調整。第一個里程碑聚焦家具示意與尺寸，透過可試用的完整流程驗證判讀教學；不以擴大符號數量作為完成標準。

## Solution

提供獨立的「學看家具與尺寸」入口，新手可直接使用，不必先完成符號學習或找找看。以約五分鐘為內容與操作的設計目標，讓使用者走完四步導讀、陌生範例練習，並取得可帶去詢問建商的提問清單。

導讀沿用現有三房兩廳，以具體位置或局部範例串起四件事：

1. 圖上的家具表示什麼。
2. 哪些尺寸確實有標示。
3. 放得下家具之後，還有哪些使用空間需要確認。
4. 缺少資料時，應索取什麼、詢問什麼。

讀者能回到完整格局自由看圖。導讀後提供一張新的陌生房間局部圖，以及三道選擇題，依序練習辨認有依據的結論、尚缺的資訊、能補足缺口的追問。每題回饋解釋理由，也說明看似合理的推測為何尚不能確定；允許重試與回看導讀。

另提供固定、可列印的三至五題提問清單，每題附上詢問理由。清單可直接開啟，不以完成導讀或答對練習作為條件。

本里程碑讓讀者學會指出證據與資訊缺口。明列尺寸的範例可示範可重算的幾何關係；未取得所需資訊時，給出具體追問，不替讀者判定自己的家具或生活方式是否適用。

## User Stories

1. As a 正在看預售屋／新成屋的買房者, I want 知道家具示意與實際可用空間的差別, so that 我不會只因圖上畫有床就認定自己的床放得下
2. As a 尚未學過符號的新手, I want 直接進入尺寸判讀導讀, so that 我不用先完成另一套學習流程
3. As a 第一次使用拼厝的人, I want 找到名稱明確的導讀入口, so that 我知道這段內容能幫助我判斷什麼
4. As a 時間有限的讀者, I want 導讀以約五分鐘為設計目標, so that 我能用一段短時間完成一個完整主題
5. As a 買房者, I want 看見每一步對應的圖上位置或局部範例, so that 我能把說明與實際圖面連起來
6. As a 買房者, I want 知道家具圖形表示的資訊及其限制, so that 我不會把示意當成個人家具的配置保證
7. As a 買房者, I want 找出圖中確實標出的尺寸, so that 我能區分資料與目測推測
8. As a 買房者, I want 知道標示尺寸量的是哪一段, so that 我不會把整體外框尺寸當成房間可用尺寸
9. As a 買房者, I want 範例清楚標出單位與示範假設, so that 我知道計算使用了哪些條件
10. As a 買房者, I want 理解家具放入後仍需確認走動、開門與使用櫃子的空間, so that 我知道下一步該查什麼
11. As a 買房者, I want 資訊不足時看見具體的缺口與追問, so that 我能向建商取得有用的資料
12. As a 讀者, I want 來回查看導讀步驟, so that 我能重新理解不熟悉的地方
13. As a 想自由探索的人, I want 回到完整格局看圖, so that 我能把局部資訊放回整戶的關係中
14. As a 讀者, I want 使用一張未在導讀中解過的房間局部圖練習, so that 我能檢查自己是否會運用所學
15. As a 讀者, I want 練習辨認有依據的結論, so that 我能指出圖面真正支持什麼
16. As a 讀者, I want 練習辨認尚缺的資訊, so that 我能發現結論中未被證明的部分
17. As a 讀者, I want 練習選出能補足缺口的追問, so that 我能把不確定轉成可採取的行動
18. As a 讀者, I want 每題作答後看到正誤與理由, so that 我理解答案，而非只記住選項
19. As a 讀者, I want 知道看似合理的錯誤選項為何證據不足, so that 我能辨認常見推測
20. As a 讀者, I want 可以重試練習與回看導讀, so that 我能修正剛才的誤解
21. As a 準備詢問建商的人, I want 直接開啟三至五題的精簡提問清單, so that 我不用先完成課程才拿得到問題
22. As a 準備詢問建商的人, I want 每個問題都有詢問理由, so that 我知道建商的回答要補足什麼
23. As a 準備看屋的人, I want 列印提問清單, so that 我能帶到接待中心使用
24. As a 不想輸入個人資料的人, I want 不填家具尺寸或建案資料也能使用, so that 我能直接學習與取得清單
25. As a 回訪的人, I want 隨時重新開啟內容, so that 我不受完成紀錄或先前答案限制
26. As a 手機使用者, I want 看清楚局部圖、尺寸、選項與理由, so that 螢幕大小不會妨礙判讀
27. As a 鍵盤或螢幕閱讀器使用者, I want 取得與圖面等價的資訊並完成練習, so that 我不必依靠目測或滑鼠
28. As a 想核對說法的讀者, I want 區分可查證的主張與範例假設, so that 我知道結論成立的條件
29. As a 內容維護者, I want 每個結論都能追溯到出處或可重算的範例尺寸, so that 我能核對與更新內容
30. As a 內容維護者, I want 圖面、解釋、選項與列印清單使用一致的內容, so that 修改一次不會留下互相矛盾的版本
31. As a 產品維護者, I want 觀察讀者在另一張範例上的獨立判讀, so that 我能區分完成流程與實際理解

## Implementation Decisions

### 交付與使用流程

- 第一批交付四步導讀、一張陌生房間局部練習圖、三道選擇題，以及三至五題固定提問清單。
- 導讀有獨立入口；清單有可直接開啟的穩定入口。導覽接入現有網站，不要求登入、完成符號學習或通過測驗。
- 四步可前後查看；導讀能前往練習與清單，也能回到完整格局自由看圖。練習可回看導讀、查看回饋並重試。
- 約五分鐘是內容長度與操作的設計目標，不是倒數計時、強制限時或成功判定。
- 選擇題只檢查當下的判讀，不把正誤轉成房屋評分、個人適用評分或既有符號熟悉度。
- 清單採網站內容的列印呈現，不需要新建文件產生或下載系統。紙面保留問題與詢問理由，排除導覽和答題控制。

### 內容與證據

- 教學與答案依讀者當下可取得的圖面標註與範例文字成立。內部幾何欄位未展示時，不算讀者已知的資訊。
- 每個教學結論要有可查核的出處，或明列且能重算的範例尺寸。出處記錄足以回到原文的文件與定位資訊；範例記錄假設、單位及推導依據。
- 外部資料須實際讀取原文、自行白話改寫。示範假設清楚標示；來源不支持的通用數值先不收錄。
- 幾何示範的結論只涵蓋明列條件，不能從單一尺寸計算推導普遍舒適度、施工可行性或個人生活適用性。
- 新判讀主張另行查證。既有 Symbol 的 Source Tier、Verification Status 與畫法出處不能當成判讀結論已驗證的證明；不把新主張塞入原有符號的 caution。
- 查不到依據時，內容具體指出缺少什麼資料及可提出的問題，不以肯定語氣補上未知資訊。
- 清單中的示例問題包括索取房間淨尺寸、確認家具示意尺寸；正式三至五題依完成查證的導讀內容編寫。

### 圖面與資料的責任

- 沿用現有 Layout／FloorPlan 與圖面 Module。資料、SVG 圖面與教學文字各自承擔原有責任；需要的新局部呈現或尺寸標註由最小必要的 Interface 擴充處理。
- FloorPlan 仍由程式產生；局部呈現與教學標示不以手改既有產物或另畫相互矛盾的家具圖形來實現。
- 顯示有尺寸的示範時，標註與圖面幾何使用同一份依據。刻意缺少標註的範例保留缺口，不偷偷補足答案所依賴的資料。
- 現有前台只呈現整體外框尺寸，房間內尺寸與局部圖呈現不能視為已完成能力。後續架構需檢查資料投影、圖面留白與標註位置後再擴充。
- 導讀內容、圖面參照、練習選項、答案理由與清單維持單一可維護內容來源；瀏覽器取得呈現所需資料，內部查證備註留在內容維護流程。
- 延續靜態建置與現有設計語言；正式路由、內部型別與 Module 的細部 Interface 由後續架構／切票定案，本 spec 不預設通用課程平台。

### 判讀練習

- 判讀練習是新的內容語意，由自身 Module 持有選項與回饋。既有找找看的 Answer 是選定 Hotspot 的 Symbol 比對，不能用假的 Symbol／Hotspot id 代替判讀選項。
- 三題各檢查一個學習成果，選項與理由只能依範例已呈現的條件成立。正式內容校對須確認正解唯一，且錯誤選項的問題說得清楚。
- 每題作答後呈現正誤與理由；作答前的文字、圖面標示與無障礙描述不洩漏答案。
- 圖面的等價文字描述保留可見標註與缺少標註的情況，不新增原圖未提供的尺寸或答案。正誤以文字與形狀表達。
- 第一批是形成理解的練習，回饋可能幫助後續題目；這三題的完成情況不等同於試用者已通過獨立遷移驗收。

### 狀態、可及性與既有能力

- 導讀位置與練習狀態只在本次使用期間持有；不另存完成狀態、續讀進度或跨裝置紀錄。重新進入可重新開始。
- 既有找找看與符號熟悉度保留原有語意，新練習不讀寫它們作為學習資格或判讀進度。
- 新控制、選項、回饋與圖面說明支持鍵盤、螢幕閱讀器與手機閱讀；尺寸不能只靠在螢幕上目測才能得知。
- 圖面標示遵守既有 State 與設計語言。導讀步驟不借用檢視器的 Stage，題目正誤不放進共享圖面 Module。
- 若使用既有自由看圖與說明卡，延續兩段式選取、視野與說明卡的既有 contract。新導讀的版面細節需在架構／設計時遵守現行規則。

## Testing Decisions

### 主要 Seam：實際頁面的完整使用流程

優先沿用既有真瀏覽器頁面測試的 Seam。測試從讀者可操作的入口跨過同一個 Interface，驗四步導讀、陌生範例作答與回饋、回看／重試，以及直接開啟／列印清單。觀察可見結果、導航、資訊與可及性，不以內部元件樹、私有狀態欄位或 helper 呼叫作為成功標準。

既有入口與導航、圖面、找找看回饋、鍵盤與窄螢幕的真瀏覽器測試是 prior art；能沿用既有測試支援時不另建測試架構。列印呈現另以瀏覽器列印 media 驗證，並人工檢視列印預覽。

至少涵蓋：

- 新手可直接進入導讀；四步對應正確圖面內容，能前後查看與返回完整格局。
- 新範例有三題；至少驗一次正確與一次錯誤選擇的理由、重試及回看流程。
- 已標示與缺少的資訊在圖面、說明、選項及無障礙描述中一致；未展示的內部尺寸不成為題目的已知條件。
- 清單能直接開啟，有三至五題且各有理由；列印呈現保留內容，不裁切必要文字或圖面。
- 新練習不改動既有符號熟悉度；儲存不可用時仍能完成本里程碑流程。
- 手機 375 × 812、窄螢幕 320 × 568 與既有桌面代表尺寸可讀可操作，無水平溢出。鍵盤可完成作答與導覽，回饋可被輔助技術取得。
- 若擴充共用圖面，針對受影響的自由看圖、找找看、尺寸與縮放行為執行既有回歸檢查。

### 沿用建置資料驗證的 Seam

對新增內容延伸既有建置驗證，而非依每個 UI 各自補救。攔下無效圖面參照、缺少選項或理由、無效答案參照，以及缺少出處／範例推導依據的主張。明列尺寸的標註與計算需能核對，刻意缺少的資訊不可被自動當成零或已知值。

結構驗證不代表語意已查證。正式內容還需人工核對原文、範例條件、答案唯一性與誤解回饋；完成紀錄留在內容查證工作中。

### 人工教學驗收

- 找五位接近預售屋／新成屋買房情境的讀者試用，記錄是否完成與出現的誤解。
- 導讀與練習後，換用另一張未解過的局部範例，不提供答案提示；請讀者說出一項有依據的觀察、一項尚未確認的資訊，以及一個能補足缺口的追問。
- 同一位讀者必須獨立完成三件事才算達標；五位中至少四位達標。
- 反覆出現的誤解須修正並重新確認，不以多次重試後答對原題代替陌生範例驗收。
- 這是小規模教學試用門檻，不是市場需求或所有買房者學習成效的統計證明。
- 程式與內容驗收、人工試用皆完成後，才可宣告此里程碑驗收通過。排程與招募方式不設定未確認的日期。

## Out of Scope

- 上傳真實建案圖、AI 辨識或分析。
- 輸入個人家具／家人需求／建案資料、自動配置與自動適用判定。
- 房屋優劣、舒適度、個人適用或買不買的評分與推薦。
- 使用者帳號、完成紀錄、續讀進度、跨裝置同步與個人化清單。
- 新增完整格局、為增加數量而擴充符號，以及建立通用課程或題庫平台。
- 本次即交付動線、採光通風、結構改動、濕區維修等後續完整主題。
- 插座、電氣配線、弱電、給排水與消防設備圖。
- 獨立 PDF／Word 產生系統或額外分析報表；清單以網站的列印呈現交付。

## Further Notes

### Phase 2 與 Phase 3 的方向

Phase 2 分批把符號辨識推進到整張格局判讀。家具示意與尺寸是第一個里程碑；動線、採光資訊限制、結構及濕區，以及完整新格局保留為候選。根據本批試用、內容查證與公開後的使用證據決定下一個里程碑，再各自寫 spec，不一次把整個 Phase 2 切成實作票。

Phase 3 的住宅設備圖方向保留，優先候選是插座與弱電點位；它不屬於本里程碑。舊 Phase 1 PRD 中「階段二 AI 分析」的預留欄位是歷史方向，本次已確認的 Phase 2 不以它們作為交付或架構前提。

### 本次規格與後續工作的界線

需求已經過 Q1–Q13 與完整摘要確認。本文件規定產品結果與最低實作約束；主要測試 Seam 提案為上述頁面流程，內容資料另沿用建置驗證。後續架構／切票需落實圖面資料、教學內容與判讀練習的責任，並完成實際文案、來源與範例查證。本 spec 的存在不代表新教學內容、程式、圖面或試用驗收已完成。

後續首次定義新領域用語時再更新 CONTEXT；若需推翻既有 ADR 或設計規則，先明載理由與受影響決定。本 spec 未推翻既有圖面、找找看或品牌 ADR。
