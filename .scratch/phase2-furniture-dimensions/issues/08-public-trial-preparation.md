# 08：備妥公開自填試用入口與回收表單

Status: ready-for-agent
Blocked by: 07
Spec: ../spec.md
Design: ../design-brief.md

## 背景

2026-10-05 使用者決定改用 Threads 公開招募，取代原規劃的五位受主持目標讀者試用。第 07 票已完成的第二張圖與判準仍可用；原 `4/5` 人工門檻不再是本里程碑驗收條件。本票只備妥公開流程，不預填真實回覆。

## 交付

讀者可從單一公開招募網址按「四步導讀 → 三題練習 → 第二張未解過的圖 → 匿名表單」自行試用，維護者能取得逐份原始文字作答與基本流程背景；網站保持靜態建置。

## 驗收

- [ ] 公開招募入口清楚說明試用順序、約需時間、匿名資料用途與停止自由；手機上可按順序走到第二張圖和表單，不依賴主持者切頁。
- [ ] 第二張圖的三項自由文字欄位分開且必填：有依據的觀察與圖面元素、尚未確認的具體資訊、對應缺口的建商追問；送出前不顯示示例答案、判準或他人回覆。
- [ ] 表單收最少的自述背景／流程資訊，不要求姓名、電話、電郵、建案或登入；有公開可用的提交端點，維護者能逐份讀取並匯出。提交資料的保存位置、存取與刪除方式記在維護者材料。
- [ ] 招募連結引導讀者先走導讀及練習；若可直接開第二張圖，報告以流程自述區分，不能假裝技術上保證了先後順序。
- [ ] 若埋 GA，僅記聚合到達／流失與表單入口或送出，不記自由文字、背景回答或個資；沒有 GA 也不阻擋表單試用。
- [ ] 真瀏覽器核對手機、桌面、鍵盤及表單提交／匯出；重新執行受影響的建置與回歸測試，並記錄公開網址及實際驗證結果。

## 驗證

用測試回覆演練一次完整流程，核對三段文字在回收端保持原文與欄位對應；刪除測試回覆後再公開。檢查表單設定不向下一位讀者顯示前人回答。正式真人結果留第 09 票。
