# 08：完成五人教學試用，修正誤解並確認結果

Status: ready-for-human
Blocked by: 07
Spec: ../spec.md
Design: ../design-brief.md

## 交付

與使用者協作招募並完成五位接近預售屋／新成屋買房情境讀者的無提示試用，依第 07 票材料記錄各人的獨立判讀結果；必要時修正反覆誤解並重測。真人參與與實際結果不能由 agent 虛構。

## 驗收

- [ ] 五位符合目標情境的真實讀者按同一程序試用，留下可核對但不暴露不必要個資的記錄；招募與執行日期以實際發生時填寫。
- [ ] 導讀與三題練習後，讀者在另一張未見過的局部圖上，無答案提示地分別指出有依據的觀察、未知資訊及有效追問；逐人記錄三項結果與所需提示。
- [ ] 至少四位讀者各自獨立完成三項任務；原題多次重試後答對不能替代此判定。
- [ ] 對反覆出現的誤解追到相應內容或介面，修正並重新確認；保留改動與重測結果，不以未修正的門檻數字掩蓋問題。
- [ ] 程式、內容與人工試用條件皆滿足後才將本票標記 resolved，並記錄本里程碑的實際驗收結論。未完成時維持待人工驗收。

## 驗證

- 核對五份逐人記錄、三項任務的判定及至少四人門檻；檢查反覆誤解的修正與重測證據。
- 如修改產品內容或程式，重新執行相應建置、頁面及回歸檢查，再記錄最終版本與驗收日期。
