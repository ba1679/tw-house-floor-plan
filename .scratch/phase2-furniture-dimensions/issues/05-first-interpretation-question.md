## 驗收

- [x] 新局部範例有可維護的原始描述與生成產物，沿用 FloorPlan／Renderer 的幾何及畫法；它不進入公開完整 Layout 清單，也不新增另一戶完整格局。

- [x] 第一題有唯一正解；各選項及正誤理由已人工校對，能解釋看似合理的推測哪裡缺少依據，且可追到來源或可重算的示範條件。
- [x] 選項在確認前可更改；確認後就近呈現文字與形狀表意的正誤及理由，能重試。不顯示總分、能力等級或房屋評分。
- [x] 判讀練習持有自己的作答狀態，不偽造 Symbol／Hotspot id，不讀寫找找看的 Familiarity；本機儲存不可用時仍能作答。
- [x] 建置攔下無效圖面或答案參照、缺少選項／理由／依據；手機、鍵盤與輔助技術能完成作答。
