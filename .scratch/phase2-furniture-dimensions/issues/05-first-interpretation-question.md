# 05：用陌生局部圖完成第一道判讀作答

Status: ready-for-agent

Spec: ../spec.md

## 交付

以一張導讀未解過的房間局部圖完成「有依據的結論」第一題，提供選項、確認、正誤與理由、重試的完整作答流程。

## 驗收

- [ ] 新局部範例有可維護的原始描述與生成產物，沿用 FloorPlan／Renderer 的幾何及畫法；它不進入公開完整 Layout 清單，也不新增另一戶完整格局。
- [ ] 圖面、明列條件及等價文字只呈現讀者可取得的資訊；答案不能依賴未標出的內部尺寸，作答前的可見及輔助技術內容不洩漏答案。
- [ ] 第一題有唯一正解；各選項及正誤理由已人工校對，能解釋看似合理的推測哪裡缺少依據，且可追到來源或可重算的示範條件。
- [ ] 選項在確認前可更改；確認後就近呈現文字與形狀表意的正誤及理由，能重試。不顯示總分、能力等級或房屋評分。
- [ ] 判讀練習持有自己的作答狀態，不偽造 Symbol／Hotspot id，不讀寫找找看的 Familiarity；本機儲存不可用時仍能作答。
- [ ] 建置攔下無效圖面或答案參照、缺少選項／理由／依據；手機、鍵盤與輔助技術能完成作答。

## 驗證

- 真瀏覽器走一次正確與錯誤選擇、確認、理由及重試；核對作答前不洩漏答案、Familiarity 不變及本機儲存不可用的情況。
- 執行資料驗證、靜態建置及新圖面可能影響的共用 Renderer 回歸；人工記錄答案唯一性與來源核對。
