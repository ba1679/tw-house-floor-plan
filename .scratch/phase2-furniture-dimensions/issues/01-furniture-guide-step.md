# 01：讀懂家具示意的第一個完整步驟

Status: claimed
Blocked by: none
Spec: ../spec.md
Design: ../design-brief.md
Architecture: ../architecture.md

## 交付

建立可直接開啟的「學看家具與尺寸」導讀第一步，以現有三房兩廳的主臥局部圖說明家具示意能提供什麼、不能證明什麼，並能返回完整格局。這一票須完成正式內容、圖面、頁面及驗證，不只建立空白架構。

## 驗收

- [ ] 第一個步驟有可直接開啟的穩定入口；不要求先學符號、完成找找看或提供個人資料。
- [ ] 家具示意的正式文字已讀取並核對原始來源或明列的範例依據；讀者看得到核心判讀理由，維護者能找到來源定位與查證紀錄，不直接發布概念圖文字。
- [ ] 導讀內容、圖面參照、讀者可見條件與查證備註有單一可維護來源；瀏覽器只取得呈現所需的內容，建置會攔下無效圖面參照及缺少依據的主張。
- [ ] 主臥局部圖沿用現有 FloorPlan、生成資料及 Renderer；裁切與留白足以辨認床、門與相關空間，不另畫或手改家具。等價文字只描述讀者可見資訊。
- [ ] 手機依圖面再文字的順序自然閱讀，桌面圖文相鄰；核心理由、查看依據及返回完整格局均可用。此步驟不保存進度、不借用檢視器 Stage。
- [ ] 新頁面及受影響的完整格局、兩段式選取與尺寸呈現沒有回歸；正式實作前先依 DESIGN.md 檢查視覺規則。

## 驗證

- 真瀏覽器從直接入口走完第一步、查看依據及返回完整格局；檢查手機、桌面、鍵盤焦點與圖面等價文字。
- 執行建置資料驗證、靜態建置及共享圖面受影響的既有測試；記錄正式內容的來源定位與人工核對結果。
