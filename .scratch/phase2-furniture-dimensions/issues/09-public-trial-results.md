# 09：招募公開試用，分析回答並修正反覆誤解

Status: ready-for-human
Blocked by: 08
Spec: ../spec.md
Design: ../design-brief.md

## 交付

發布已驗證的公開招募連結，按預先記錄的條件收集匿名表單回覆，逐份分析第二張圖的三項文字作答；用實際證據修正反覆誤解，交付有樣本限制的試用報告。真實讀者與回覆不得由 agent 虛構。

## 驗收

- [ ] 發布前記錄招募文案、網站及表單版本、招募起訖、有效回覆與排除條件；發布日期及來源以實際發生時填寫。
- [ ] 保留逐份原始回答，去除不必要個資；另記背景與流程自述、空白／重複／未循流程的排除數量及理由。
- [ ] 依第 07 票的三項判準逐份評閱觀察、未知資訊與對應追問，記錄可核對的例子與反覆誤解。報告分開列「符合自述目標情境」與其他回覆；不設定或聲稱 `4/5` 門檻。
- [ ] 如有反覆誤解，追到對應的導讀、練習、圖面或問卷措辭，修正並以後續新回覆重新觀察；保留原版與新版結果，不混為同一批。
- [ ] 報告列各階段流量（若有 GA）、有效／無效回覆數、三項文字判讀結果、限制與下一步。樣本不足時如實寫「尚無法判斷」；不宣稱代表買房者母群或證明教學因果成效。
- [ ] 程式、內容與公開試用資料檢查皆完成後才標記 resolved；若沒有真實回覆或尚未處理反覆誤解，維持待人工資料狀態。
