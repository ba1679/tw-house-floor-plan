# 04：把資訊缺口變成追問，取得可列印清單

Status: ready-for-agent
Blocked by: 03
Spec: ../spec.md
Design: ../design-brief.md
Architecture: ../architecture.md

## 交付

完成導讀第四步，並提供可直接開啟、含三至五個完整問題及詢問理由的固定提問清單；同一頁可用瀏覽器列印。

## 驗收

- [ ] 第四步把前面已核對的資訊缺口轉成具體追問；四步可前後查看、查看依據及返回完整格局。尚未交付的練習沒有死連結。
- [ ] 清單有穩定直接入口，不要求完成導讀、答對題目、登入或可用的本機儲存；每題都有「問什麼」及「為什麼問」，正式問題與導讀內容共用一份來源。
- [ ] 清單的三至五題只涵蓋本批查證支持的內容，不做房屋評分或未確認的法律承諾；來源與範例條件經人工核對。
- [ ] 螢幕及列印使用同一份問題與理由。列印保留標題、適用範圍、題目與理由，排除導覽與作答控制，不裁切必要內容。
- [ ] 四步及清單在手機、桌面、鍵盤與輔助技術上可讀可操作；建置驗證包含問題參照及依據。

## 驗證

- 真瀏覽器驗完整四步、直接開啟清單、鍵盤與窄螢幕；以 print media 驗頁面內容，並人工檢視實際列印預覽。
- 執行靜態建置、資料驗證及受影響的既有回歸；記錄清單各題與導讀缺口的對應。
