# 06：三題練習與全站入口串成完整使用流程

Status: ready-for-agent
Blocked by: 04, 05
Spec: ../spec.md
Design: ../design-brief.md
Architecture: ../architecture.md

## 交付

在同一張陌生圖上補齊「尚缺資訊」與「有效追問」兩題，串起四步導讀、三題練習、提問清單、回看與重試，並加入首頁與格局頁的必要入口。

## 驗收

- [ ] 三題依序檢查有依據的結論、尚缺的資訊及有效追問；各題有唯一正解、選項理由與正式依據，第三題與第四步及清單的追問語意一致。
- [ ] 一次只呈現一題，讀者確認後看完就近回饋再自行進下一題；可回看導讀及重試。結束畫面可前往清單，但沒有總分、通過標章或解鎖門檻。
- [ ] 首頁有名稱明確的導讀入口，原「讀這張圖」仍是主要 CTA；格局頁入口不增加壓縮圖框的常駐列，也不覆蓋必要圖面。清單與練習均可依各自入口直接使用。
- [ ] 正式圖面、選項、理由、無障礙描述及清單使用同一份可維護內容；作答前不洩漏答案，未知資訊不被寫成已知。
- [ ] 新練習不讀寫 Symbol Familiarity，不冒用既有找找看的 Analytics 事件；儲存不可用時完整流程仍可用。
- [ ] 鍵盤及輔助技術可取得回饋；375 × 812、320 × 568 和桌面代表尺寸沒有必要內容被裁切或水平溢出。依 DESIGN.md 檢查入口與版面。

## 驗證

- 真瀏覽器從首頁及格局頁走完導讀、三題回饋、清單、回看／重試，也直接開啟練習與清單；涵蓋鍵盤、窄螢幕、儲存不可用及 Familiarity 不變。
- 執行新增內容的建置驗證、靜態建置及既有首頁、格局、找找看、尺寸與縮放的受影響回歸；記錄三題答案唯一性的人工校對。
