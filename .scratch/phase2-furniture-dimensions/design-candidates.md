# 設計結構候選（已選 C）

這是 shape 的比較材料，不是方向 contract。後續已確認 C 設計 brief，並依提案切票；仍未授權產品實作。依據現有 spec 與 DESIGN.md；延續既有品牌。模式為 Read，練習局部為 Operate。

## 結構候選

1. 四步章節式導讀：每一步是可自然捲動的短閱讀頁，局部圖與正文相鄰。
2. 連續圖文導讀：四章放在同一篇閱讀頁，以目錄和章節連結回查。
3. 圖文對照閱讀：正文逐段推進，桌面相鄰圖面同步對應；手機每段附相應圖。
4. 證據筆記：每一步的圖面與「有依據／待確認／可以怎麼問」建立可見對應。
5. 兩張圖比較：比較已明列條件與缺少標註的示例，四步仍依序成立。
6. 逐步讀圖：圖面為主，當步的一個觀察與短說明切換，保留前後與步驟導覽。
7. 問題引導閱讀：由具體追問開始，沿四步說明為何需要該資料；清單仍可直達。

本輪比較第 4、2、6 種結構；工具種子 64ce99aa。相同品牌、相同交付範圍，不引入陌生手勢、課程帳號、完成評分或持久化進度。

## 共通流程與邊界

- 首頁只新增清楚的「學看家具與尺寸」入口，保留「讀這張圖」主要 CTA；不將首頁改成課程首頁。
- 既有格局頁只接入必要入口，不能新增常駐列壓縮圖框。入口所在位置需與原本標題／操作列一起驗證高度；不增加覆蓋圖面的教學彈窗。
- 四步導讀 → 一張陌生局部圖上的三題練習 → 固定提問清單。清單可直接進入，不要求完成前兩段。
- 練習一次呈現一題、提供選項與明確確認動作；作答後就近呈現正誤與理由，不以色彩單獨表意。允許重試與回看，不顯示總分或通過標章。
- 提問清單使用閱讀版面；每題保留「要問什麼／為什麼問」。列印保留必要文字，去掉導覽與操作，不設計自訂 PDF 系統。
- 不把導讀硬塞進既有自由看圖的一屏限制；自然捲動、放大文字與窄螢幕要能承載內容。共用圖面規則與既有自由看圖互動不變。
- 明確區分「圖上標註」、「示範假設」、「未提供的資料」。前台提供可查核出處，但不照搬 Symbol Source Tier 徽章，避免誤用既有查證語意。
- 概念圖為 AI 產生的設計比較稿，不是正式平面圖、教材證據或成品驗收。

## 共通互動草案

練習採「選一個選項 → 確認答案 → 正誤與理由 → 下一題」，不選完立即跳題。三題對應同一張陌生局部圖，明列條件緊鄰圖面；回饋解釋正確選項及選錯時誤用了哪個推論。回看導讀與重試都是普通連結或按鈕，不用彈窗。`第 1 題，共 3 題` 只表示目前位置，不是能力等級或完成率。

提問清單採三至五個編號條目；每條是完整問題及詢問理由，不加入個人化輸入、勾選追蹤或完成鎖。頁首提供列印控制與返回導讀；列印版只保留主題、問題、理由及必要的適用範圍文字。不可用大圓角卡片增加紙面長度。

手機圖面與說明依閱讀順序上下排列；桌面可以分欄，但 DOM 與輔助技術的閱讀順序一致。圖上資訊有等價文字；觀察位置不需要靠點中很小的床、櫃子或尺寸線。導讀步驟切換後焦點移到當步標題；答題回饋在題目附近可被取得，不自動搶走焦點。來源／範例假設以明確文字連結或展開區呈現，核心判讀理由不能藏起來。

切換步驟以立即、克制的內容更新為主，不做翻頁動畫、假立體紙張或裝飾性推拉縮放。頁面內容增加或文字放大時自然捲動，不靠縮小文字維持一屏。
