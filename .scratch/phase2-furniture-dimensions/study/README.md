# 家具與尺寸：五人教學試用材料

狀態：**可試用；人工教學驗收尚未執行。** 第 08 票要以真實讀者完成五份紀錄、檢查至少四人獨立達標，並修正及重測反覆誤解。

## 材料與順序

1. 讀者自行使用網站的四步導讀 `/guides/furniture-dimensions` 與其後的三題練習。清單可直接開啟；不把練習答對當作驗收結果。
2. 主持者照 [主持流程與判準](moderator.md)切換到**另一張**讀者局部圖 `/study/furniture-dimensions`。這個頁面不從一般導覽連入；正式試用前不要預先展示。
3. 每位讀者複製一份[逐人紀錄表](participant-record-template.md)，填真實作答、所需提示及誤解；最後彙入[五人總表](cohort-summary-template.md)。主持者材料與紀錄不得給讀者看。
4. 以 [整合核對紀錄](../../../docs/reference/phase2-study-materials-validation.md)核對網站版本與圖面依據。正式試用若網站內容或圖面改動，須重新核對受影響項目。

第二張圖的原始描述在 `data/study/bedroom-transfer.layout.json`，展開產物在同目錄的 `bedroom-transfer.floorplan.json`。它是臥室乙與相鄰走道的教學示意，不是實際建案或完整 Layout。讀者只看到房間局部；內部幾何與走道入口不是作答條件。

## 交付邊界

本套材料讓同一主持流程可以執行五人試用；目前沒有讀者結果、招募日期或市場證據。完成網站測試只表示**可試用**。第 08 票的人工教學驗收，須另依真實紀錄判定。
