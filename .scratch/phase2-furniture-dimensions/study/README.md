# 家具與尺寸：公開自填試用材料

狀態：**第二張圖可讀；公開入口、表單及真實回覆尚未完成。** 2026-10-05 使用者決定以 Threads 公開招募取代五人受主持試用；原 `4/5` 門檻不再適用。[第 08 票](../issues/08-public-trial-preparation.md)準備流程與提交端點，[第 09 票](../issues/09-public-trial-results.md)執行招募、分析及修正。

## 公開試用順序

1. Threads 只分享正式部署後的**招募入口**，由該入口引導四步導讀 `/guides/furniture-dimensions` 與三題練習。不要分享 `localhost` 或直接把第二張圖作為招募連結。
2. 練習後，讀者自行前往 `/study/furniture-dimensions` 看**另一張**局部圖，接著填[表單題目與設定稿](public-form-blueprint.md)。原練習的答案與回饋不可在表單題目中重述；表單送出前不顯示本圖答案或他人回答。
3. 維護者依[招募貼文草稿](threads-post-draft.md)發文，在發布前記下網址、版本、招募起訖與有效回覆條件。匯出逐份回答後，依[結果分析模板](public-results-template.md)整理；保留原文與排除原因，按購屋情境及網站／表單版本分開看。
4. 以[第 07 票整合核對](../../../docs/reference/phase2-study-materials-validation.md)確認圖面依據。正式試用若網站內容、圖面或問卷改動，須重新核對受影響項目並分開比較版本。

第二張圖的原始描述在 `data/study/bedroom-transfer.layout.json`，展開產物在同目錄的 `bedroom-transfer.floorplan.json`。它是臥室乙與相鄰走道的教學示意，不是實際建案或完整 Layout。讀者只看到房間局部；內部幾何與走道入口不是作答條件。

## 交付邊界

現在沒有公開表單端點、招募日期或讀者結果；現有 `/study/furniture-dimensions` 仍無站內入口，尚不能直接拿去 Threads 招募。GA 若啟用，只能補充到達／流失；理解程度必須看三段原始文字。公開便利樣本不代表買房者母群，也不能證明教學因果成效。

舊的[受主持流程](moderator.md)、[逐人紀錄](participant-record-template.md)與[五人總表](cohort-summary-template.md)保留作為已完成第 07 票的歷史材料；新試用不以它們的五人門檻判定。
