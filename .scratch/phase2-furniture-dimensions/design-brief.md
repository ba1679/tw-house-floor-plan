# 家具與尺寸判讀：C「逐步讀圖」設計 brief

依據：[已確認 spec](spec.md)、現行 DESIGN.md 與 CONTEXT.md。視覺參考為 [C 概念圖](assets/guided-plan-concept.png)，核准範圍是閱讀方向，不是逐像素照製 AI 圖稿。

## 1. 對象與任務

服務正在看預售屋／新成屋、尚不熟悉圖面判讀的一般買房者。主要情境是看屋前或回家後，使用手機或電腦慢慢讀圖；清單則可帶去詢問建商。

導讀是 Read：讓人看懂圖面提供的依據及其限制。練習是局部的 Operate：選擇答案並理解理由。不將讀圖做成需要註冊、解鎖或累積完成率的課程平台。

## 2. 結果與證明

完成這段內容後，讀者應能指出一項有依據的觀察、一項仍缺的資訊，以及一個能補足缺口的問題。約五分鐘是內容與操作長度的目標，不是計時或資格限制。

圖面、明列的範例條件及可查核的出處是教學依據。未顯示的內部尺寸不視為讀者已知；家具示意不能直接推導個人家具是否適用。內容查證及五人試用門檻依 spec 執行，概念圖不能替代這些證明。

## 3. 選定方向

**一張局部圖、一個觀察、一步接一步。** 圖面是視覺焦點，每一步只處理一件事；標題、短說明與操作服務於這張圖，不搶成主視覺。

四步維持已確認的內容順序：家具示意 → 尺寸依據 → 使用空間 → 怎麼追問。不是把四篇文章全部展開，也不改成 A 的密集證據表。短說明仍須交代本步能確定什麼、尚不能判定什麼；核心理由直接可見，來源或範例條件可另外展開核對。

保留既有拼厝品牌、系統 sans、純色閱讀背景、白色圖面、細框及 State 規則。概念圖中的 AI 重畫幾何、紙／地板紋理、過大的標題及圖說都不沿用。正式圖面由既有資料與 Renderer 呈現，不以這張 PNG 替換。

## 4. 範圍與頁面關係

本輪涵蓋導讀、判讀練習、固定提問清單與必要入口；不重做既有品牌、符號條目、自由看圖及找找看。

- 首頁新增「學看家具與尺寸」學習入口，保留「讀這張圖」作為主要 CTA，不改成課程首頁。
- 格局頁增加必要的導讀入口，但不新增常駐列壓縮圖框、不覆蓋圖面。位置需連同既有標題及操作列一起確認窄螢幕高度。
- 主要路徑為「四步導讀 → 陌生局部圖的三題練習 → 提問清單」。導讀可前後查看，也可前往完整格局。
- 清單有直接入口，不要求讀完導讀或答對練習。可列印，但不做新的 PDF／Word 產生系統。

## 5. 狀態與內容範圍

導讀固定四步；練習固定一張陌生局部圖及三題；清單三至五題，各附詢問理由。

- 導讀：當步、上一個／下一個、回到完整格局、開啟清單、查看依據。第一步沒有前一步；第四步的主要下一步是換圖練習。
- 練習：未選、已選待確認、已作答並顯示理由、下一題、三題結束、重試與回看。
- 三題結束：提示可回看或取得清單，不給總分、能力等級、通過標章或房屋評分。
- 狀態只服務本次使用，不另存完成或續讀紀錄，不改既有符號熟悉度。未完成或選錯都不鎖住清單。

本里程碑使用靜態內容，不新增遠端載入、帳號、個人家具輸入、收藏或個人化清單的 UI。缺少尺寸是教學資訊缺口，不是系統錯誤，不以補零或虛構數值消除。

## 6. 互動與版面

### 手機導讀

依序呈現：既有 header → 回到完整格局 → 頁名及清單入口 → 四步導覽／當步位置 → 大幅局部圖及短圖說 → 當步觀察標題、短說明及依據入口 → 上一個／下一個。

圖面、觀察與短說明形成同一個閱讀單位。圖說如「主臥局部・教學示意圖」是次要說明，不是頁面的最大標題。來源／條件入口不藏起核心判讀理由。

四步導覽用數字、主題文字與當步形狀／字重提示位置，不只用顏色。普通點擊或鍵盤即可切換；不要求點中床、尺寸線等小目標，不增加滑動手勢門檻或教學彈窗。

導讀是自然捲動的閱讀頁，不套用既有自由看圖的一屏限制。內容較長或文字放大時，操作留在正常文件流，不用浮動底列擋住圖面，也不縮小圖中文字換取一屏塞滿。

### 桌面導讀

左側主要圖面、右側當步標題及短說明，步驟切換維持圖文相鄰。寬度不足時回到手機的上下閱讀順序，不做兩個相互競爭的內部捲動區。

### 判讀練習

同一張陌生圖及明列條件配合三題，一次顯示一題。流程為「選一個選項 → 確認答案 → 就近呈現正誤與理由 → 下一題」；不選完立即跳走，也不自動越過回饋。

`第 1 題，共 3 題` 只表示位置。正誤以文字與形狀表達，沿用既有克制的回饋語言，不使用紅綠、慶祝動畫或抖動。回饋不下放給共用圖面，也不與符號找找看共用答題語意。

### 提問清單

使用三至五個清楚的編號條目，每條是「完整問題＋為什麼問」。列印控制與返回導讀在頁首；不增加勾選追蹤、個人化輸入或大圓角卡片。列印版保留主題、問題、理由及必要的適用範圍文字，移除導覽與操作。

### 可及性與轉換

維持既有對比、焦點、觸控目標及 reduced-motion 規則。圖面等價文字只描述可見標註與缺少資料，不洩漏答案。四步切換後焦點移至當步標題；作答回饋就近提供給輔助技術，不突然把焦點移走。

頁面資訊在手機、桌面及 DOM 保持合理閱讀順序；檢查 375 × 812、320 × 568、桌面及文字放大，無水平溢出。步驟更新以立即、克制為主，不設翻頁動畫或裝飾性縮放。
