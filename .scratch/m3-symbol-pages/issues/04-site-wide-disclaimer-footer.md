# 04: 免責聲明進全站頁尾

**What to build:** 不管使用者落在哪一頁，捲到底都看得到「本網站符號說明為一般通用慣例，不同建商／設計師畫法可能有差異，實際請以個案圖說或現場人員說明為準」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

規格：`.scratch/m3-symbol-pages/spec.md` 的「全站」。PRD §6.4 要求每頁固定顯示。

## 現況

文案常數已經存在，註解也已經寫著「每頁固定顯示」，但**目前只有說明卡在用**。M3 會多出首頁、3 張分類頁、14 張符號頁，全部沒有。

## 注意

**說明卡裡那一份要保留。** 卡片升起來時會蓋住頁尾，兩份服務的是不同時刻的同一個人——這不是重複。

**這張票會改變平面圖頁的可視高度，而檢視器的數學吃這個數字。** 視野的 fit 與上下限是**相對當前的框**算的（ADR-0004），框的高度來自一次 ResizeObserver 觀測（ADR-0003：說明卡是版面裡的一列）。頁尾一加，框就變矮。必須確認既有行為沒有被推歪——這是這張票唯一真正的風險，驗收條件裡那條「既有測試全綠」不是形式。

- [ ] 首頁、分類頁、符號頁、平面圖頁捲到底都看得到免責聲明
- [ ] 文案一字不改，來自既有的常數，不在元件裡重打一次
- [ ] 說明卡底部那一份保留，行為不變（固定在最底、不隨捲動消失）
- [ ] 平面圖頁加了頁尾之後：375px 下圖面仍不溢出、pan/zoom 與兩段式點擊照常、說明卡開合照常
- [ ] 既有的 67 條測試維持綠
