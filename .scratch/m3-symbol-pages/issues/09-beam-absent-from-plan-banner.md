# 09: 樑的「圖上看不到」橫幅

**What to build:** 「樑」的符號頁底部不說「打開三房兩廳，標出這個符號」——那會帶使用者去看一個不存在的東西。它說「**這張三房兩廳上看不到樑——這正是重點 →**」。按下去照樣進平面圖，但圖上跳出一條說明：建案平面圖多半不畫樑，它在施工圖與結構圖上。你看不到它，所以要問。

**Blocked by:** 08（走同一個網址與同一個機制）

**Status:** ready-for-agent

規格：`.scratch/m3-symbol-pages/spec.md` 的「樑（0 個匹配熱區）」。PRD §6.2.1 的例外。

## 為什麼不是把按鈕拿掉

「圖上找不到」本身就是內容。樑在 floorplan 上刻意沒有熱區（PRD §4.2），而那正是這個符號要教的事——轉換率照樣量得到，而且這一頁的說服力更強。

## 注意

**走同一個網址、同一個機制，特例只落在呈現上。** 不要為樑開一條分支路徑：帶 0 個匹配熱區進去是一個合法的狀態，差別只在畫面上顯示什麼。

**不開說明卡。** 兩個理由：使用者剛在符號頁讀完同樣的內容，再推一次是重複；而且說明卡在 M2 是綁著「選中了某個熱區」才開的，沒有熱區硬要開卡會弄髒那條規則。

- [ ] 樑的符號頁按鈕文案是「這張三房兩廳上看不到樑——這正是重點 →」
- [ ] 按下去進到平面圖，**沒有**說明卡跳出來
- [ ] 圖面上出現橫幅說明，文案講清楚樑為什麼不在圖上
- [ ] 橫幅關得掉；關掉之後圖面的操作完全正常
- [ ] 橫幅在的時候 pan / zoom / 兩段式點擊照常
- [ ] 其他 13 個符號的行為不受影響（帶有匹配熱區的照樣高亮，不出現橫幅）
- [ ] 375px 下橫幅不遮住圖面到無法操作的程度
