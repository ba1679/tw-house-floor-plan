# Phase 2 第一步：家具示意的範例查證

查證日期：2026-10-04（Asia/Taipei）

範圍：[票 01](../../.scratch/phase2-furniture-dimensions/issues/01-furniture-guide-step.md)，現有 `3b2l_standard` 的主臥局部。

查證方式：實際讀取本專案生成的 FloorPlan JSON，透過 codegraph 取得並核對目前 Renderer 的逐字原始碼，再核對 spec 與領域定義。本次查證涵蓋資料及畫法；交付頁面的裁切、文字可讀性與真瀏覽器核對由票 01 的實作驗證完成。

## 可以成立的結論

這個教學範例畫出了床、衣櫃與門窗的相對位置，主臥面積顯示為 3.0 坪；它沒有把床的長寬、房間淨尺寸或讀者自己的床尺寸提供為明示條件。因此，**僅憑這一步提供的資訊，還不能判斷讀者的床是否放得下**。

前半是本教學範例的可核對觀察，後半是資訊缺口的推論：圖上的一張床，與讀者自己使用的床是否相同大小，沒有給定；圖上的面積也沒有提供房間淨長寬。這個推論沒有宣告圖中的床放不下，也沒有推導一般住宅的舒適度、法規門檻或施工結果。

| 資訊 | 第一步是否可作為明示條件 | 原因 |

以下皆自行撰寫，限定於這張教學範例，不引用概念圖上的文字。實作者可將它們整合進本步的單一內容來源。

**標題**：家具畫進去了，你的床就放得下嗎？

**觀察**：這個教學範例畫出了床、衣櫃與門窗的相對位置，主臥標示為 3.0 坪。

**核心理由**：局部圖沒有標出床的長寬或房間淨尺寸，也沒有提供你的床有多大，因此還不能判斷你的床是否放得下。

**讀者可見條件**：三房兩廳的主臥局部；床、衣櫃與門窗可見；未標出床的長寬與房間淨尺寸；未提供你的床尺寸。

**查看依據**：本步依據本站的三房兩廳教學範例。局部圖畫出床、衣櫃、門窗，並標示主臥 3.0 坪；沒有床的長寬與房間淨尺寸。這些資訊只能支持圖中位置的觀察，還不足以與你的床作尺寸比較。

**圖面等價文字**：三房兩廳的主臥局部，房間內有床和衣櫃，周邊可見門與窗。圖上標示主臥及 3.0 坪，未標出床的長寬或房間淨尺寸。
