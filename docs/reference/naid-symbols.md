## 2. 平面圖的基本約定（比符號本身更重要）

這一節是 renderer 與教學內容的地基。

### 2.1 平面圖是「離地 120～150cm 水平切一刀，往下看」

> p44 §15.2 原文：「平面圖為約在地面上 120~150cm 平切下視，作正投影，所得之剖面圖……此一剖面不論其距地板高度為若干，**均須切過該層所有門窗開口**……需在圖中標示出柱、外牆、隔間牆、門窗、房間用途和尺寸、地板鋪面及高程、表面材料、家具及設備物等。」

這一句解釋了整套畫法的邏輯，也是教學網站最值錢的一段內容：

- **高櫃畫 X**（p25 表 10 備考：「以 120~150cm 平切下視為原則」）→ 因為它被切到了
- **半高櫃畫斜線**（p25 備考：「120~150cm 半高櫃加斜線表示」）→ 剛好在切面附近
- **矮櫃只畫外框** → 在切面以下，是「看到的」不是「切到的」
- **書桌吊櫃畫虛線**（p25 備考：「書桌吊櫃以虛線表示」）→ 在切面**以上**，投影下來
- **樑畫長虛線**（p18 表 6）→ 同理，樑在頭頂上

一句話：**實線＝切到的或看得到的，虛線＝頭頂上的。**

### 2.2 比例尺（p8 §5、p9 表 3、p44）

- 室內設計平面圖**通常 1/50**；面積過大可放寬到 1/100 ～ 1/200
- 標記法：`S:1/50`、`1:50`、`1/50`，**位置在圖名右方**
- 圖名格式（p14 圖 8）：`一樓平面配置圖 S:1/50 mm`，圖號 `ID-1` 置於圖面下方

### 2.3 尺寸單位（p7 §4）

**以公厘（mm）為原則，且不另寫單位符號。** 15m 寫成 `15,000`。
（本專案內部用 cm，輸出標註時要嘛換算成 mm、要嘛明寫 `cm` 單位 —— 不能寫裸數字讓人誤讀成 mm。）

### 2.7 方位與展開面（p16 §10）

- 平面配置圖**原則上以圖之上方為北方，並應標示指北針**（圖 17：圓內一支黑白對比的箭頭，頂端標 `N`）
- **展開面指示**：室內圖的方向由**出入口**決定，「作圖時出入口應置於圖面**下方或右方**為原則」（圖 18／19：圓周四向標 A/B/C/D，A 在下方）
- 洩排水方向用細長箭頭（圖 20）

### 2.8 尺寸標註（p19 §12）

- 尺度線用**細實線**，與尺度延伸線垂直；端點符號為 **箭號 Arrow／點號 Dot／短斜線 Tick** 三選一，**不得混用**
- 尺度數字註於尺度線**上方**
- **「平面圖之尺寸標示，應有固定家具尺寸、單元空間尺寸及總尺寸三層標示。」**（§12(d)）
- 指標線（leader）用細實線，與水平線成 **45° 或 60°**，避免與尺度線或外形線平行
- 材料、構造圖的**斜線**一律「右上左下」
- 截斷線用中實線；**樓梯的切視線以 60° 左下右上**表示
