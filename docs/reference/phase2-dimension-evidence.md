# Phase 2 第二步：尺寸依據核對

核對日期：2026-10-04（Asia/Taipei）  
範圍：[票 02](../../.scratch/phase2-furniture-dimensions/issues/02-dimension-evidence.md)，本站 `3b2l_standard` 教學範例。

## 第一手資料與計算

來源為 [FloorPlan JSON](../../data/layouts/3b2l_standard.floorplan.json) 的 `bounds` 與 `annotations`，以及 [FloorPlanRenderer](../../components/FloorPlanRenderer.tsx) 的 `Dimensions`／`Dimension`。這是本站生成的教學範例，不對應特定建案的實測圖。

| 標註 | 起點 → 終點（圖面 cm） | 重算 | 圖上文字 | 所量範圍 |
| --- | --- | --- | --- | --- |
| `dim-overall-w` | `(0, 0) → (977, 0)` | `977 − 0 = 977 cm` | `977 cm` | 左、右外牆的牆心線之間 |
| `dim-overall-h` | `(0, 0) → (0, 782)` | `782 − 0 = 782 cm` | `782 cm` | 上、下外牆的牆心線之間 |

`bounds.width = 977`、`bounds.height = 782`；兩筆標註端點正好落在四面外牆的牆心線上。`wall-001` 至 `wall-004` 的牆心線分別位於 `y=0`、`y=782`、`x=0`、`x=977`，厚度都是 `24 cm`。牆體由牆心線往兩側各延伸 `12 cm`，所以**標註量的不是畫面上牆的最外緣，也不是房間淨尺寸**。

Renderer 將水平標註畫在圖上方留白、垂直標註畫在左側留白，兩端使用短斜線，並以細線接回對應的外牆牆心線；文字直接取用 `label`。教學圖仍使用同一份 FloorPlan 與 Renderer，不把尺寸線所在的留白當成所量範圍。

教學圖在窄螢幕顯示完整外框時，只放大這兩筆標註的字，並增加上方與左側留白；標註端點及線的位置未改。320 × 568 與 375 × 812 的真瀏覽器測試核對字級至少 12px、文字邊界完整、頁面無橫向溢出。第一步局部圖與完整檢視器維持原畫法。

建置驗證要求本步引用的兩筆標註都存在、分別對應外牆牆心線的橫向與縱向端點，且 `label` 等於端點距離加 `cm`。測試分別破壞參照、外牆牆心線與標註文字，確認建置拒絕不一致資料。

## 未知資訊與主張邊界

完整圖面沒有主臥淨長寬、床或衣櫃長寬的尺寸標註。FloorPlan JSON 中的房間與家具幾何用於生成圖形；未向讀者標出的內部數值，不列入本步可用的尺寸證據。`3.0 坪` 是主臥的面積標示，不給出淨長寬，也不能證明個人家具放得下或門、櫃可正常使用。

本步不引入新的尺寸示範、不推算走道寬度或舒適度門檻。讀者若要比較自己的床，須另取得房間淨尺寸、自己的家具實際尺寸，並確認門與櫃子使用空間。這是缺口與追問方向，不是對特定房屋適用性的判定。
