# 以雙尺度拼圖標記與讀圖桌重塑拼厝識別

原本的 B2 數位圖鑑 App 以純白、灰色卡片與單色平面圖線框為主，適合站在現場快速確認一個符號，卻沒有呈現這個產品更主要的情境：看屋前與回家後，人會坐下來對一張格局反覆閱讀、比較與練習。

正式品牌改為**拼厝（Phin-Chhù）**。其完整標記用不同比例的平面圖色塊拼成台灣意象，採木質棕、磚紅、清水灰、米白與深褐外框；它承接「起厝」與「拼湊」的在地語感，但不把網站做成房屋銷售或復古裝飾品。

完整標記只能用在首頁 hero、品牌介紹與 OG 圖等足夠大的情境。header、favicon、app icon 使用從同一份幾何簡化的 compact mark。兩個呈現藏在同一個品牌標記 Module 裡，呼叫端只選擇尺寸 variant 與淺／深表面；因此不會讓 header、首頁、favicon 和分享圖各自維護一份 logo SVG。

頁面採原型 C 的讀圖工具骨架：格局入口與下一步比裝飾更早出現。原型 B 的窗花格線只當低密度的編輯節奏，不能變成資料格、覆蓋圖面或使用在所有頁面。日光花磚的高彩色探索不納入日常產品。

品牌色不對應房間、分類、答題正誤、熟悉度或 Hotspot State。圖面與 State 的 token contract 保持不變；答題結果的擁有權仍在 Round／`QuizRound`，而不是 `FloorPlanViewport`。

## Considered Options

- **延續 B2 數位圖鑑 App**：拒絕。它清楚但過於中性，和拼厝的名稱及台灣在地記憶沒有形成辨識。
- **將完整台灣拼圖縮小成所有 icon**：拒絕。色塊與輪廓在 favicon／header 尺寸失去辨識，也會使線條糊成裝飾。
- **採用日光花磚高彩度作為全站色系**：拒絕。它能吸引注意，但會搶走平面圖，並提高使用者把品牌色誤讀為空間或狀態語意的風險。
- **以彩色標記房間與答題對錯**：拒絕。這會破壞既有圖面內容與 State 的可及性語意，也違反「分類不用顏色」的規則。

## 2026-10-01 — 使用者核准的色彩調整

使用者提供新版品牌素材，並明確核准更新色票及指定房型的地板填色。色票與房型配對以 [`DESIGN.md`](../../DESIGN.md) 為現行規則；本 ADR 原先的色票與「房間不用品牌色」限制由該決定取代。房型色保留房名並獨立於答題判定與 State；雙尺度品牌 Module、讀圖桌骨架及 Round 的作答 ownership 繼續適用。
