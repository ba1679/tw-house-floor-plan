## 重現

從 repository 根目錄執行：

```sh
python3 .claude/skills/floorplan-generator/scripts/expand_layout.py data/layouts/3b2l_standard.layout.json -o data/layouts/3b2l_standard.floorplan.json
npm run validate:floorplan
npm run test:domain
python3 .claude/skills/residential-floorplan-domain/scripts/validate_domain_rules.py --plan data/layouts/3b2l_standard.floorplan.json --rules .claude/skills/residential-floorplan-domain/knowledge/adjacency-rules.json --fixtures .claude/skills/residential-floorplan-domain/knowledge/fixture-dimensions.json --context data/layouts/3b2l_standard.domain-context.json --output docs/reviews/3b2l-domain-2026-09-16.json
```

validator 回傳 1 表示存在概念設計 blocker，2 表示輸入錯誤。0 只表示未發現已實作檢查的 blocker；`unknown` 與 warning 仍須處理。建置已串接 geometry + domain 檢查。
